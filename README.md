## Selected projects

- **[CCattler](https://github.com/boyadzhievb/ccattler)** — A Kubernetes-alternative container orchestrator built around facts, rules, and continuous reconciliation. It replaces the usual object hierarchy and YAML manifests with a declarative language, rule-based controllers, and pluggable simulator, process, and container runtimes. Written in Go; 1,600+ tests and validated on real multi-host clusters. [Documentation](https://ccattler.org).

- **[vmherd](https://github.com/boyadzhievb/vmherd)** — A lightweight Vagrant alternative for Linux. Provisions local libvirt/KVM virtual machines from official, checksum-verified cloud images, using cloud-init and a project-level `Herdfile`. Written in Go.

- **[iptables-viewer](https://github.com/boyadzhievb/iptables-viewer)** — A Kubernetes iptables explorer that turns node firewall rules into an interactive Cytoscape graph. Includes a token-protected API, Docker support, and a Kubernetes DaemonSet deployment.

- **[Property Rental](https://github.com/boyadzhievb/property-rental)** — An offline-first property management application for short-term rentals. Built with React, TypeScript, and Capacitor. All data stays on-device in IndexedDB, with no backend or telemetry. Available as a web app and native Android/iOS applications.
